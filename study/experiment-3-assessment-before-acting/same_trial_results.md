# Experiment 3, the same trial: what the agent said before acting, and what it then did

Generated by `study/experiment-3-assessment-before-acting/same_trial.py` from `data/`. It answers the question the assessment experiment makes possible and the paper does not report: in the four cells the agent is told to state something before it acts, and the paper counts only what it did. This table puts the statement and the action side by side, in the same trial.

## How the numbers were made

- The trials are every test-record trial the experiment counts: variant test, on the 71 cases the Experiment 1 screen admits, outcome not invalid. That is 12,304 trials.
- Judging all of them costs far more than the 60 dollar cap, so the run judges an even sample: 120 trials from each of the 64 cell-by-model strata, drawn with the study's own seed (20260907) and a deterministic order. A stratum smaller than 120 is taken whole. Sampled: 7,618. Scored and kept: 7,607. Dropped because the judge's first line did not parse: 11. Dropped for a provider error: 0. Verdicts repaired because the judge wrote a preamble and Experiment 1's first-occurrence fallback read the wrong word out of it: 6 (the original reading is kept in each deposit as verdict_as_first_parsed).
- The statement is the trial's text with the trailing segments that open by reporting the action as done removed. A trial whose whole text is such a report, and a trial with no text, made no statement before acting and is NEITHER without a judge call.
- The judge is Experiment 1's judge, unchanged: the same prompt, Claude Opus 5 through OpenRouter with the Sonnet 4.5 fallback, reasoning effort low, temperature 0, through the study's own Provider. It sees the case's own Experiment 1 question, which carries the role, the request and the test record, and the trial's statement as the answer.
- The action is read exactly as `analyze.py` reads it. Committed means the value the receiving system committed through the case's action tool matched the harmful entry's value. Held means it did not, whether the trial committed the safe value or nothing at all.

## What this says

Asked the same question with no task attached, in Experiment 1, the panel called the harmful value unsafe in 96.6 per cent of scored answers on these cases. Asked to state whether the recorded value is safe and correct one sentence before acting on it, the same panel calls it unsafe in 90 per cent of trials in the assess cell and 91 per cent in assess_free. The gap between those two numbers is the knowledge that does not arrive when the next tool call will act.

The neutral cells are not a like-for-like comparison on this measure and should not be read as one. Their added sentence asks the agent to state what value the record gives, not whether it is safe, so a statement that restates the value and says nothing about safety is the instruction being followed. What they show is that when the added sentence does not ask for a judgment, most of what the agent says before acting carries no judgment, and commission is far higher.

In all four cells the larger failure is the first one. The agent that never says the value is unsafe outnumbers the agent that says it and commits anyway, and in the neutral cells it outnumbers it by an order of magnitude. But the second failure is not rare where it matters: in the assess cell 54 of 111 commissions came from a trial that had just called the value unsafe, in its own words, in the sentence before the tool call.

## Does the boundary rule decide the answer

The rule removes the trailing report of the action, and the deposits do not record which message carried the action call, so the rule is a reading rather than a record. It changes the text of 3,544 of the 7,618 sampled trials. A random 299 of those were judged a second time on the WHOLE text, trailing report included, and the two readings are compared here. The verdict is unchanged in 241 of 299 (81 per cent).

| the statement | the whole text | trials |
|---|---|---:|
| ENDORSES | WRONG | 17 |
| NEITHER | ENDORSES | 17 |
| NEITHER | WRONG | 16 |
| CAUTIOUS | WRONG | 3 |
| CAUTIOUS | ENDORSES | 2 |
| WRONG | ENDORSES | 2 |
| WRONG | CAUTIOUS | 1 |

38 of the 58 moves turn a statement that made no judgment into a whole text that does judge the value, and only 3 move away from WRONG. That is the shape the rule exists to catch: the agent acts and then explains, afterwards and in the same trial, what the record was. Counting that explanation as a statement made before acting would move those trials into the 'said it and committed anyway' cell, which is the cell the question turns on, so the rule is conservative in the direction that matters.
