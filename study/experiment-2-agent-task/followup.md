# The follow-up study: twenty cases, run once, reported apart

Generated by `study/analysis/analyze.py`. These twenty cases (ids beginning `N_FU_`, family `followup`) were written after the 78-case bank and run once; their cases are in `cases/cases.json`. They are reported apart from the bank on purpose: pooled with the set that shaped the design they would answer a different question. No number in the four experiments above includes a single one of these trials.

Everything below uses the bank's own rules unchanged: the same admission screen, the same sixteen models, the same equal-model estimator with the same 2,000-draw bootstrap, the same exact matching of the committed value, and the same three control sets, with each follow-up case read case by case from its request and both of its records.
