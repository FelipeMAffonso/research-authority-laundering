# AI agents can commit actions their own language models call unsafe

This repository accompanies the paper "AI agents can commit actions their own language models call unsafe" by
Felipe M. Affonso.

The study package is archived at Zenodo: <https://doi.org/10.5281/zenodo.22817867>. It holds every answer and
trial of the four experiments as one row (the knowledge check, the agent task, the assessment before acting and the
real-system tests), one gzip JSON Lines file per model for each experiment and per system and placement for the
real-system tests, together with the case bank, the analysis script that produces every number, table and figure
in the manuscript, the script that checks every reported number against the analysis, and the audit records.
Sixteen language models from eight developers, 33,289 trials and 29 real systems are covered. All records are
fictional, and no live service was reached.

The data are released under the Creative Commons Attribution 4.0 International license (CC BY 4.0).
